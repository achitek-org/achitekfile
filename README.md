# Achitekfile

A [Tree-sitter](https://tree-sitter.github.io/tree-sitter/) backed semantic parser for the Achitekfile DSL.

> [!NOTE]
Active development has moved to the [`achitek-ls`](https://github.com/achitek-org/achitek-ls) workspace.
The `achitekfile` crate continues to be published to crates.io, but releases,
issues, documentation, and source changes are now managed from that repository.
